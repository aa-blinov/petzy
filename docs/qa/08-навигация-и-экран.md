## NAV-01. Нижняя панель на месте

- **Шаги:** Сдвинуть окно браузера и прокрутить страницу вниз.
- **Ожидаем:** Панель не уходит за край экрана.
- **Результат:** ✅ проверено
- **Как проверено:** e2e `check_bar_stays.py` (8 утв.); e2e `check_bar_chrome_toolbar.py` (12 утв.)

## NAV-02. Подсветка вкладки не лезет на страницу

- **Шаги:** Посмотреть страницу над панелью на узком экране.
- **Ожидаем:** Над панелью нет цвета подсветки.
- **Результат:** ✅ проверено
- **Как проверено:** e2e `check_tab_bar.py` (3 утв.)

## NAV-03. Свайп назад только жестом назад

- **Шаги:** Быстрый свайп от левого края на пустом месте, затем свайп по карточке, полю и блоку с горизонтальной прокруткой.
- **Ожидаем:** Назад уходит только на пустом месте.
- **Результат:** ✅ проверено
- **Как проверено:** e2e `check_swipe_back.py` (5 утв.)

## NAV-04. Несохранённая форма

- **Шаги:** Изменить поле в записи и нажать «назад».
- **Ожидаем:** Спрашивает, выйти ли без сохранения.
- **Результат:** ✅ проверено
- **Как проверено:** вручную: вкладка «Лента»: спрашивает «Выйти без сохранения?»; «Остаться» оставляет на форме с введённым значением; кнопка «Назад» в шапке: спрашивает «Выйти без сохранения?»; системная кнопка «назад» браузера: спрашивает «Выйти без сохранения?»

## NAV-05. Неизвестный адрес

- **Шаги:** Открыть `/nonexistent`.
- **Ожидаем:** Экран «Такого адреса нет».
- **Результат:** ✅ проверено
- **Как проверено:** вручную: несуществующий адрес говорит «Такого адреса нет»

## NAV-06. Без горизонтальной прокрутки

- **Шаги:** Открыть основные экраны при ширине 320, 360 и 390 px.
- **Ожидаем:** Горизонтальной прокрутки нет, текст переносится.
- **Результат:** ⚠️ проверено частично
- **Как проверено:** вручную: / при 320 px без горизонтальной прокрутки (лишние 0 px); /medications при 320 px без горизонтальной прокрутки (лишние 0 px); /documents при 320 px без горизонтальной прокрутки (лишние 0 px); /medical-card при 320 px без горизонтальной прокрутки (лишние 0 px); /settings при 320 px без горизонтальной прокрутки (лишние 0 px); / при 360 px без горизонтальной прокрутки (лишние 0 px); /medications при 360 px без горизонтальной прокрутки (лишние 0 px); /documents при 360 px без горизонтальной прокрутки (лишние 0 px); /medical-card при 360 px без горизонтальной прокрутки (лишние 0 px); /settings при 360 px без горизонтальной прокрутки (лишние 0 px); / при 390 px без горизонтальной прокрутки (лишние 0 px); /medications при 390 px без горизонтальной прокрутки (лишние 0 px); /documents при 390 px без горизонтальной прокрутки (лишние 0 px); /medical-card при 390 px без горизонтальной прокрутки (лишние 0 px); /settings при 390 px без горизонтальной прокрутки (лишние 0 px); e2e `check_user_paths.py` (125 утв.)
- **Не проверено:** перенос текста при 320 px вручную не проверяли, проверяли только прокрутку

## NAV-09. Широкий экран

- **Шаги:** Открыть приложение при ширине 1280 px.
- **Ожидаем:** От 1024 px нижняя панель становится левой колонкой: так задумано в стилях для широких экранов. Телефон (390 px) сохраняет нижнюю панель. Боковой панели с отдельными разделами нет (обещание из README убрано, см. QA-06).
- **Результат:** ✅ проверено
- **Как проверено:** вручную: на широком экране нижняя панель на месте (низ 800); боковой панели на широком экране нет, как в коде
- **Находка:** QA-06

## NAV-10. Обновление страницы на правке

- **Шаги:** Открыть `/medications/<id>/edit` и обновить страницу.
- **Ожидаем:** Экран восстанавливается, данные на месте.
- **Результат:** ✅ проверено
- **Как проверено:** вручную: для проверки создана запись 8,1; после перезагрузки страницы поле показывает 8,1 (в поле «8.1»)
