# Решения владельца по находкам аудита

Дата: 6 октября 2026. Аудит снят по коду `9ec7e78`, находки лежат в документах
экранов этого каталога. Ниже то, что решил владелец, и то, что сознательно
оставлено как есть.

## Что делаем

| Что | Решение | Где чинить |
| --- | --- | --- |
| «Добавлен <дата>» у документа по зоне телефона | Хранить зону события у документа, новое поле и миграция, время одинаково у всех | `web/documents.py`, `web/schemas.py`, `frontend/src/pages/DocumentsList.tsx` |
| Замена файла документа при правке | Сделать замену, старый файл удаляется только после успешной загрузки нового | `web/documents.py`, `frontend/src/pages/DocumentForm.tsx` |
| Прогресс и «Остановить» у обычных файлов | Добавить всем файлам, как у архивов | `frontend/src/services/documents.service.ts`, `frontend/src/pages/DocumentForm.tsx` |
| Отзыв ссылки на медкарту | Право оставляем любым участником доступа, переписать подпись в Настройках, что это общие ссылки | `frontend/src/pages/Settings.tsx`, `frontend/src/pages/MedicalLinks.tsx` |
| Владелец открывает свою ссылку для ветеринара | Показать кнопку «Медицинская карта», если у человека есть своя сессия; без сессии не показывать | `frontend/src/pages/SharedMedicalCard.tsx`, `frontend/src/utils/publicPages.ts` |
| Повторное удаление аккаунта после обрыва | Сделать повторный DELETE идемпотентным: сервер помнит, что аккаунт удалён, и отвечает успехом без проверки пароля | `web/account_deletion.py`, `web/db.py`, новая коллекция `deleted_accounts` |
| Протухшая ссылка сброса пароля | Проверять токен при открытии страницы, сразу говорить «ссылка не сработала» и дать ссылку на новое письмо | `web/account.py`, `frontend/src/pages/ResetPassword.tsx` |
| «По необходимости» у курса лекарства | Отдельный признак в модели, режим не выводится из пустого расписания | `web/medications.py`, `web/schemas.py`, `frontend/src/pages/MedicationForm.tsx` |
| Одновременная правка заметки к приёму | Как у анкеты для врача: при расхождении говорить «изменили в другом месте» и показывать чужой вариант | `web/medical_card.py`, `web/schemas.py`, `frontend/src/pages/VisitPrepForm.tsx` |
| Частые пароли | Показывать подсказку под паролем, не отправляя форму; список остаётся на сервере | `web/auth.py`, `frontend/src/pages/Register.tsx` |
| Повторное письмо для входа | Говорить прямо: «письмо уже отправляли недавно, ещё одно придёт позже» | `web/account.py`, `frontend/src/pages/ForgotPassword.tsx` |
| Список людей в админке | Сделать поиск и постраничность | `web/users.py`, `frontend/src/pages/AdminPanel.tsx` |
| Питомцы в карточке человека | Сделать их ссылками на медкарту питомца | `web/users.py`, `frontend/src/pages/UserProfile.tsx` |
| Не прошло одно приглашение из трёх | Сказать, чьё именно не прошло, и убрать из списка тех, у кого доступ уже есть | `web/pets.py`, `frontend/src/pages/PetForm.tsx` |

## Что оставляем как есть

| Что | Почему |
| --- | --- |
| Числа в предпросмотре удаления аккаунта | Перечня питомцев и фразы «вместе с записями, лекарствами и документами» достаточно |
| Четвёртая возможность «не сейчас» в согласии на обработку данных | Согласие остаётся обязательным, окно закрывается только решением: дать согласие, удалить аккаунт или выйти |

## Отдельно от владельца, не решение

Скачивание архива уходит со страницы через смену адреса. Проверяется только на
установленном приложении на телефоне, здесь не проверяется.
